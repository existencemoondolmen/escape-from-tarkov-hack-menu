## 🧩 About

**Escape from Tarkov Menu** is a curated list of Escape from Tarkov open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot reference viewer, raid status panel
- **Quality-of-Life Helpers** — stash organizer notes, ammo chart viewer, quest tracker notes
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Map Layout Notes — study interchange, customs, and woods routes
- Loot Reference Viewer — browse item values and spawn notes
- Quest Tracker Notes — organize task objectives for study
- Raid Timer Panel — track in-raid time for practice runs

### Wallhack
- Stash Organizer Notes — plan inventory sorting by category
- Ammo Chart Viewer — compare penetration and damage values
- Build Planner Notes — save weapon mod configurations for reference

### Aimbot
- Offline Mode Notes — study maps without online pressure
- Hideout Planner — track upgrade requirements and materials
- Config Presets — keep separate settings for study sessions
